# 错题集 User Story 列表（现有功能补录）

> 说明：本文档基于当前代码实现反向补录，描述系统已具备的能力。角色统一为「学生/使用者」。

## 一、错题录入

### US-01 手工新增错题
作为使用者，我希望通过表单新增一条错题（年级、科目、来源、题号、类别、错题日期），以便把做错的题目记录下来。
- 类别默认「做错」，日期默认今天，状态默认「错误」
- 年级/科目/来源会记住上次输入并自动预填

### US-02 录入题目与答案图片
作为使用者，我希望在新增错题时上传题目图片和答案图片，以便保留原题截图。
- 支持多选文件，仅接受图片类型
- 支持在弹窗内 Ctrl/Cmd+V 直接粘贴剪贴板图片

### US-03 录入答案文字
作为使用者，我希望填写「答案文字」，以便没有图片时也能记录解法。

### US-04 CSV 批量导入
作为使用者，我希望上传 CSV 批量导入错题，以便快速录入大量题目。
- 表头：`年级,科目,错题来源,题号,类别,错题日期`
- 首行按表头跳过，格式错误的行自动忽略，导入后状态统一为「错误」
- 导入完成提示成功条数

## 二、错题查询与浏览

### US-05 按年级筛选并记忆
作为使用者，我希望顶部年级下拉可切换（高一上～高三下/全部）且被记住，以便下次打开直接看当前学期。
- 年级保存在 localStorage，切换即刷新列表

### US-06 多条件组合筛选
作为使用者，我希望按科目、状态（多选）、类别（多选）、错题日期区间、来源关键字组合筛选，以便快速定位题目。
- 同组内为「或」，组间为「且」
- 日期：填两端为区间，只填一端为精确匹配，起始日期不得晚于结束日期
- 提供「清除筛选」重置条件（仅保留年级）

### US-07 列表浏览与分页
作为使用者，我希望以表格查看错题（年级/科目/来源/题号/类别/日期/状态/重做次数/附件/操作），并分页浏览。
- 每页 100 条，支持首页/上一页/页码/下一页/末页
- 状态以彩色徽章展示；附件列展示「题图 / 答案 / 试卷」标记

### US-08 查看题目附件
作为使用者，我希望在编辑弹窗中查看已上传的题目/答案图片，以便回顾原题。

## 三、错题维护

### US-09 编辑错题
作为使用者，我希望编辑已有错题的全部字段（含手动修改状态），以便纠正录入错误。
- 修改年级/科目/来源时，服务端会同步搬移已上传文件的存储目录

### US-10 增删附件
作为使用者，我希望在编辑时新增或删除单个附件，以便替换错误的图片。
- 删除前二次确认，磁盘文件同步删除

### US-11 删除错题
作为使用者，我希望删除一条错题，其重做记录与附件一并清除，以便保持列表整洁。

## 四、重做（复盘）

### US-12 记录一次重做
作为使用者，我希望为某道错题登记一次重做（日期 + 结果：通过/错误），以便跟踪掌握情况。
- 日期默认今天

### US-13 查看重做历史
作为使用者，我希望查看某题的全部重做记录，以便了解反复出错的过程。

### US-14 批量重做
作为使用者，我希望勾选多道题后按同一日期与结果批量登记重做，以便高效复盘整套题。
- 完成后提示处理条数

### US-15 状态自动流转
作为使用者，我希望状态随重做结果自动更新，以便无需手工维护。
- 重做「通过」：当前「反复错」→「反复错后通过」；曾有错误重做→「反复错后通过」；否则→「通过」
- 重做「错误」：当前「通过」或「反复错后通过」→「反复错」；「错误」再次做错→「反复错」；否则保持「错误」
- 新增重做记录会清除「已生成试卷」标记

## 五、试卷生成

### US-16 生成 PDF 试卷
作为使用者，我希望勾选若干错题一键生成 PDF 试卷，以便打印重做。
- 单次上限 200 题，超出给出中文提示
- 生成中按钮置为「生成中...」并防重复提交

### US-17 生成 Word 试卷
作为使用者，我希望同样的选题生成 .docx 试卷，以便二次编辑排版。

### US-18 是否包含答案
作为使用者，我希望通过「包含答案」开关决定试卷是否附上答案文字与答案图片，以便区分考卷与解析。

### US-19 已生成试卷标记
作为使用者，我希望已导出过的题目在列表显示「试卷」标记，以便避免重复选题。

## 六、批量选择

### US-20 勾选与全选
作为使用者，我希望逐行勾选或全选当前列表，并可「清除选择」，以便执行批量重做与试卷生成。
- 筛选变化后自动剔除不在结果中的已选项
